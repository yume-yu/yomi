# 台本を書かせる OpenWebUI のモデル

Yomi の「台本を作る」は、入力欄の文章（題材）だけを OpenWebUI に送ります。
台本の書き方はシステムプロンプトとして OpenWebUI 側のカスタムモデルに持たせ、
Yomi の設定で「一人語り用」「掛け合い用」のモデルとして選びます。

## Yomi からの頼み方

Yomi は Web UI と同じく、OpenWebUI に**チャットを作って生成を頼み**、終わるまで様子を見に行きます。
`/api/chat/completions` を素のまま呼ぶと、Web 検索もツールの往復も回らないためです
（[Server-Side Tool Calling over the API](https://docs.openwebui.com/reference/server-side-tool-calling)）。
そのため、生成の経過や出典は OpenWebUI のチャット履歴に「Yomi: …」という題で残ります
（設定で、終わったら消すこともできます）。

頼むときに Yomi が付けるもの:

- `features.web_search: true`（Web 検索）
- `variables`: `{{CURRENT_DATE}}`、`{{CURRENT_DATETIME}}`、`{{CURRENT_WEEKDAY}}`
- 設定の「一緒に有効にするフィルター ID」（例: thinking を切り替えるトグル式のフィルター）。
  Web UI のトグルや、モデルの既定のツール・機能は Web UI が自分で付けているので、API から使うときは自分で指定する
- 付けないもの: `tool_ids`（モデルに付けたノートやナレッジベースのツールは送らない）

## 作り方

1. OpenWebUI の「ワークスペース → モデル → ＋」で新しいモデルを作る
2. ベースモデルに、台本を書かせたいセルフホストのモデルを選ぶ
3. 下のシステムプロンプトを貼る
4. Yomi の設定「台本の生成（OpenWebUI）」の「一覧から」で、そのモデルを選んで保存する

## Yomi との約束ごと

- **掛け合い用のモデルは、各発言の行の頭に【A】か【B】を付けること。**
  Yomi はこの印で話し手を見分け、A と B を設定の声（既定は A が kanna、B が girl）で読み分けます。
  `A：` の形や全角の `【Ａ】` も読めますが、【A】【B】に揃えるのが確実です。
  印の付いていない行は、直前の発言の続きとして扱います。
- 推論型のモデルの `<think>…</think>` や、OpenWebUI が折りたたんで入れる `<details>…</details>` は、Yomi が取り除きます。
- **今日の日付はシステムプロンプトに `{{CURRENT_DATE}}` で入れてください。** 書式の例に具体的な日付を書くと、
  モデルがそれを今日の日付だと受け取ることがあります（例の日付は今日と関係のない日付にする）。
- 台本用のモデルには、ノートやナレッジベース、ファイル操作のツールを付けないほうが安全です。
  台本を書かずにファイルへ保存しようとしたり、過去の記憶に引っぱられたりします。
- Markdown の見出しや箇条書きは speech-proxy でも除去されますが、
  台本の段階で使わせないほうが、聞いたときの区切りが自然になります。

## 一人語り用のシステムプロンプト（例）

```
あなたは、音声で聞くための台本を書く構成作家です。
ユーザーが渡す題材をもとに、一人のナレーターが読み上げる台本を書いてください。

- 出力は台本の本文だけにする。前置きや解説、見出し、Markdown（#、*、-、表、コード）は使わない
- 耳で聞いて分かるよう、一文を短くする（40字程度まで）。括弧書きや指示語は減らす
- 英字の略語、記号、数式は、読み方が分かる形で書く（例: API → エーピーアイ、5GB → 5ギガバイト）
- 題材にない事実を付け足さない。分からないことは分からないと言う
- 長さは読み上げて3〜5分（1200〜2000字程度）。題材が短ければ短くてよい
- 話のまとまりごとに空行で区切る
```

## 掛け合い用のシステムプロンプト（例）

```
あなたは、音声で聞くための掛け合いの台本を書く構成作家です。
ユーザーが渡す題材をもとに、二人の話し手 A と B の掛け合いの台本を書いてください。
A は話を進める案内役、B は聞き手で、素朴な質問やあいづちで話を引き出します。

- 出力は台本の本文だけにする。前置きや解説、見出し、Markdown（#、*、-、表、コード）は使わない
- 耳で聞いて分かるよう、一文を短くする（40字程度まで）。括弧書きや指示語は減らす
- 英字の略語、記号、数式は、読み方が分かる形で書く（例: API → エーピーアイ、5GB → 5ギガバイト）
- 題材にない事実を付け足さない。分からないことは分からないと言う
- 長さは読み上げて3〜5分（1200〜2000字程度）。題材が短ければ短くてよい
- 各発言は1行に1つ。行の頭に必ず【A】か【B】を付ける（例: 【A】今日は〜について話します。）
- 1つの発言は1〜3文にする。同じ話し手の発言を続けない
- 話し手の名前、ト書き、効果音の指示は書かない
```
